Curated Tools & Learning Links

A compact, opinionated list of read‑first resources, tools, and training platforms — quick descriptions beneath each link. Styled to match the PT‑CheatSheet look and feel.

PayloadsAllTheThings

A huge collection of payloads and techniques for web, binary, and cloud testing — excellent reference when crafting exploits or PoCs.

The‑XSS‑Rat SecurityTesting

Community‑curated XSS and web testing examples, templates and practical guides — useful for learning attack patterns and PoC construction.

Command Injection Cheatsheet

Concise command injection tricks and payloads — very practical when you need quick escalation or RCE vectors during web testing.

RevShells

Curated reverse shell one‑liners for many platforms and languages — lifesaver for pivoting, callbacks and manual post‑exploitation steps.

Basic Linux PrivEsc (g0tmi1k)

A classic, hands‑on Linux privilege escalation writeup — start here for kernel exploits, misconfigs, SUID checks and practical checklists.

CyberChef

Browser-based “Swiss army knife” for data transformations — encoding, crypto, parsing, and quick forensic helpers. Indispensable for fast analysis.

Hashes.com — Hash Identifier

Identify hash types and run quick cracking attempts. Useful when you encounter a hash and need a fast classification plus cracking options.

SecTools.org

Community list of security tools across categories (network, web, forensics, infra) — a great place to discover alternatives and niche utilities.

GTFOBins

Command snippets and escape techniques for common system binaries that can be abused for privilege escalation on UNIX systems.

LOLBAS (Living Off The Land Binaries And Scripts)

Windows equivalent to GTFOBins — documents how built‑in Windows binaries and scripts can be leveraged by attackers or testers.

Exploit‑DB

Large, searchable archive of published exploits and PoCs — useful for tracking CVEs and practical exploit code when assessing targets.

OWASP

Official project pages, top‑10 guidance, and many free tools/docs for web security best practices and testing methodologies.

GTFOBins GitHub (mirror)

Project source and community contributions for GTFOBins — handy if you want to fork or contribute your own snippets.
